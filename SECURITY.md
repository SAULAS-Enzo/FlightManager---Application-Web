# Politique de sécurité — FlightManager

## Versions maintenues

Seule la dernière version disponible sur la branche principale (`main`) bénéficie de mises à jour de sécurité.

| Version | Supportée          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans **FlightManager**, merci de ne pas ouvrir d'issue publique afin de protéger les utilisateurs.

Pour la signaler de manière confidentielle :
1. Envoyez un e-mail à **enzojeansau@gmail.com** avec l'objet `[Sécurité] FlightManager - Description courte`.
2. Décrivez le problème de manière détaillée ainsi que les étapes permettant de le reproduire.
